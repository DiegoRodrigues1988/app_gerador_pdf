# 📱 PDF Fácil - Aplicativo de Criação de PDFs

Um aplicativo Flutter simples e intuitivo para criar, salvar e compartilhar PDFs facilmente.

## ✨ Características

- 📝 Digite ou cole qualquer texto
- 📄 Converta automaticamente para PDF
- 💾 Salve seus PDFs no celular
- 🔄 Acesse o histórico de anotações
- 📤 Compartilhe via WhatsApp, Email, etc.
- 🗑️ Delete anotações antigas

## 🚀 Como Usar

### Instalação

1. Receba o arquivo `app-release.apk`
2. Clique nele para instalar
3. Pronto! O app está pronto para usar

### Usando o App

1. **Criar PDF**: Digite seu texto e clique em "Salvar e Gerar PDF"
2. **Compartilhar**: Clique em "Compartilhar" para enviar via WhatsApp, Email, etc.
3. **Histórico**: Clique no ícone de relógio para ver suas anotações anteriores
4. **Editar**: Toque em qualquer anotação para ver os detalhes e gerar novos PDFs

## 📋 Requisitos do Sistema

- Android 5.0 ou superior
- Pelo menos 50 MB de espaço livre
- Conexão com a internet (apenas para compartilhamento)

## 🔒 Privacidade

- Todos os seus PDFs são salvos **localmente** no seu celular
- Nenhum dado é enviado para servidores
- Você tem controle total sobre seus arquivos

## 🐛 Problemas Comuns

### "Permissão de armazenamento negada"
- Vá em Configurações > Apps > PDF fácil > Permissões
- Habilite "Acesso a Arquivos"

### "Não consigo instalar o app"
- Vá em Configurações > Segurança > Instalar de fontes desconhecidas
- Habilite a opção e tente novamente

### "O PDF não foi salvo"
- Verifique se há espaço livre no celular
- Tente dar permissão de armazenamento novamente

## 📞 Suporte

Se encontrar algum problema, tente:
1. Reinstalar o aplicativo
2. Limpar o cache do app
3. Reiniciar o celular
