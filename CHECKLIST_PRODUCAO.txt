📱 PRÓXIMOS PASSOS PARA GERAR O APK:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣ CRIAR CERTIFICADO DE ASSINATURA (Fazer UMA VEZ SÓ):

   No Windows PowerShell:
   
   keytool -genkey -v -keystore "$env:USERPROFILE\key.jks" `
     -keyalg RSA -keysize 2048 -validity 10000 -alias flutter_key

   Responda as perguntas com seus dados.


2️⃣ CRIAR ARQUIVO key.properties:

   Crie um arquivo em: android/key.properties
   
   Com este conteúdo:
   ─────────────────────────────────────────
   storePassword=SUA_SENHA_AQUI
   keyPassword=SUA_SENHA_AQUI
   keyAlias=flutter_key
   storeFile=../key.jks
   ─────────────────────────────────────────


3️⃣ CONFIGURAR GRADLE (android/app/build.gradle.kts):

   Procure por "signingConfigs" e substitua por:
   
   ─────────────────────────────────────────
   signingConfigs {
       release {
           keyAlias keystoreProperties['keyAlias']
           keyPassword keystoreProperties['keyPassword']
           storeFile keystoreProperties['storeFile'] ? 
             file(keystoreProperties['storeFile']) : null
           storePassword keystoreProperties['storePassword']
       }
   }
   ─────────────────────────────────────────


4️⃣ GERAR O APK:

   No PowerShell (Windows):
   ────────────────────────
   flutter build apk --release

   Ou use o script:
   ────────────────
   .\build_apk.ps1


5️⃣ ENVIAR VIA WHATSAPP:

   ✓ O APK estará em: build/app/outputs/flutter-apk/app-release.apk
   ✓ Envie para o usuário via WhatsApp
   ✓ Pronto! Ele pode instalar direto no celular
